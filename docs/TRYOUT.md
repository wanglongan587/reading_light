# 微光阅读试用记录

对象：3—5 位“想读书但难以开始”的年轻读者。尚未实际邀请或收集反馈。

每次 15—20 分钟。使用示例书或参与者自愿提供的书；不要求展示个人心情或日记。先请参与者独立操作，再询问原因，不提前教会所有按钮。

1. 打开软件，读完首次说明，找到一本书并开始阅读。记录是否需要帮助、哪里让人犹豫。
2. 切换滚动和翻页，调整字号，离开后返回。确认是否找到原来的段落。
3. 选中一句触动自己的话，打开回响，再回到阅读。询问是否看清“原文”与“微光回复”的区别、是否觉得被打断。
4. 先确认参与者理解：本次文字会发送给 OpenAI 并可能产生费用。使用虚构心情，选择相同标签但输入不同事件，查看回答是否贴合事件，再检查日记保存与删除。拒绝联网的参与者可跳过这一项。
5. 切换三种主题，试着创建自己的主题。询问更愿意在哪个环境继续读、哪些装饰会分散注意力。
