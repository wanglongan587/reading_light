# 微光阅读 0.1.5 验证记录

日期：2026-11-14。环境：Windows x64、Rust 1.96.1 MSVC、GPUI Kit 0.9.0、WebView2、Microsoft Edge Playwright 通道。测试数据均位于 `target/` 隔离目录。书籍兼容验证使用隔离副本，真实 AI 验证只发送专门编写的测试文字，不发送个人书库或历史心情。

## 已验证

### 0.1.5 本轮增强

- 全书搜索：在 WebView 内逐章节扫描净化后的 XHTML 文本，返回章节名、上下文摘要和可定位 CFI；搜索在新查询或重开书籍时自动作废旧结果，最多保留 80 条命中，长查询和异常结构有边界处理。原生工具栏与 `Ctrl+F` 打开搜索抽屉，输入框自动聚焦，点击命中项直接回书页。
- 持久化划线：新增 `Highlight` 数据，旧版 `state.json` 通过 `serde(default)` 自动兼容。选文回响面板可以留下划线，划线在重开书籍时重新绘制到 epub.js 标记载荷；可在“所有划线”中回到原文或删除，删除同步移除书页标记且不修改书籍文件。
- 阅读进度与续读：根据 epub.js 全书 locations 计算当前位置百分比，同时保存当前章节名；书卡、阅读底栏显示进度，书架首页在有历史位置时显示《书名》、章节和百分比，并提供“继续上次阅读”主入口。
- 阅读中快捷排版：字号、行距和版心宽度作为独立的阅读偏好保存，不覆盖主题文件；调整后立即重排并对之后打开的书籍保留，也可恢复当前主题默认值。状态文件仍保持旧版兼容。
- 新功能测试：核心 21 项、桌面交互 16 项、网页 20 项全部通过。网页测试包含真实 EPUB 的跨章节搜索、划线添加/删除/重开恢复、进度随章节前进，以及原有分页、主题、损坏章节和减少动态回归。
- 使用实际《百年孤独》隔离副本完成 Windows 原生窗口链路：导入、打开、24 项目录、选文回响、划线、63 条搜索结果、模式切换、快捷排版、主题、阅读进度、心情日记、书签和位置保存均通过；使用同一数据目录重启后，划线、进度、章节、排版偏好、主题和日记全部恢复。
- 0.1.5 ZIP 解压到全新目录后再次完成同一套原生流程，日志为 `GLOW_SMOKE_OK`；压缩包执行文件与 release 构建 SHA-256 一致，校验文件匹配，精确密钥扫描、`.env`、`state.json`、`openai-config.json` 和 WebView 缓存均未进入发布包。
- 真实 OpenAI 接口复查仍返回 429 限流；应用继续正确显示限流提示、保留草稿且不写空日记。原生烟雾测试使用 `GLOW_SMOKE_FAKE_MOOD=1` 完成其余界面和保存链路，未将模拟结果记为真实 AI 验收。

### 0.1.4 本轮验证

- 心情回复根因已确认并修复：原来 `echo::respond` 每个标签只有一段预写回复，文字不能改变回答。现在心情页使用 OpenAI Responses API，文字优先于标签；阅读选文继续使用明确标注的本地示例。
- 真实 API 检验：相同“疲惫”标签，分别提交“升职想庆祝但担心新岗位”和“陪伴十年的猫离世”，收到两段分别讨论新岗位与失去宠物的回答。真实窗口再提交多行读书心情，生成、展示并保存到日记，持久化 `demo: false`，不是模拟接口结果。
- 请求只含当次文字、标签和固定说明，不含书库与历史日记；设置 `store: false`。密钥由本机文件读取，安装目录仅保存非秘密的文件引用，密钥不进入源码、日记或发布包。
- 等待期间禁止重复提交；可以继续编辑或切换页面；完成后只清空未修改的原稿，保留新草稿。停止等待会丢弃晚到回答，并提示已发请求仍可能计费。超时、权限、额度与服务异常显示可操作提示。回答生成后保存失败可用相同文字重试本机保存，不再次调用 API。
- 已修复心情页与阅读选文共用回复状态；心情页现在单独保留最近提交的输入与结果，切换页面不会误显示阅读选文。
- 心情输入改为多行文本框，实时显示字数；保存失败保留草稿，不显示新结果。
- 日记新增、收藏、删除、清空及书架移出在写入失败时回滚内存状态；用故意不可写的状态目标验证，不以正常写入测试替代失败场景。
- 文件选择后的异步回调直接更新应用实体，避免依赖已经变化的窗口关联。
- 补测后核心测试 20 项、桌面测试 13 项通过；其中桌面测试包含真实 HTTP 本地模拟服务、响应解析及 9 项原生交互回归。网页测试 16 项全部通过，已配置实际《百年孤独》及损坏 spine 样本，无跳过。
- 使用《百年孤独》隔离书库完成真实 Windows 窗口流程，包含延迟点击打开、目录、选文、回响、书签、模式和主题切换、位置保存及 AI 心情与日记。生成后自动滚动到回答；检查 1024×720 逻辑窗口、125% 缩放的渲染图，修复服务说明文字的截断。
- TypeScript 构建、Rust 格式检查及 Clippy 通过。
- 后续异常流程回归：取消选文后 Ctrl+Enter 不再提交旧选文；首章文件缺失时先检查章节内容并立即尝试备用入口，不再等待底层未结束的显示任务；失败目录跳转后的成功跳转清除错误并恢复原生状态。这三条均先复现失败，再验证修复。
- 实际翻页后关闭并重新打开恢复位置、书籍加载失败后在同一会话重新打开也通过。
- 发布版已更新到 `E:\GlowReading`，安装文件与构建文件 SHA-256 一致。以 `C:\Windows` 为工作目录运行真实 API 检验通过，确认密钥加载不依赖开发目录。
- 安装版使用旧书库与日记的隔离副本完成全流程；原有日记逐项比对一致、所有书籍保留，原始用户数据与升级前备份逐字节一致。备份保存在 `target/before-update-014/data`，没有写进发布包。

- 2026-11-13 独立补测发现并修复两处问题。“减少动态”此前只改变开关文字，书页仍被固定禁用全部动画；现在关闭时保留书内动画，开启时对已打开章节和新章节立即生效，关闭后可恢复。“移出书架”此前只删除书架记录，应用内的净化书页、封面和 TXT 原稿副本仍留在磁盘；现在成功移出后清理对应缓存目录，用户导入的原始文件保持不变。

## 已修复的联调问题

- 重复导航动作产生相同控件标识：改为稳定且区分位置用途的标识，日记卡片设独立父标识。
- 初次重排可能漏报进度：在排版完成后主动获取并回报 CFI。
- 发布版速度改变测试时序：原生测试等待实际章节文档与选文监听器就绪，不只等待加载通知。
- 隐藏原生窗口会暂停 WebView2 动画帧：窗口集成测试正常呈现测试窗口，完成后自动退出；不以隐藏窗口结果宣称通过。
- 合法 XHTML DTD 被原 XML 解析器整体拒绝：改为容错解析、白名单序列化与本地资源检查，并保留目录语义。
- EPUB 清理后丢失 `epub:type="toc"`：恢复导航语义，目录从 0 项恢复为完整章节。
- 手绘 SVG 在 GPUI 实际界面中未显示：生成并内嵌 PNG，截图确认视觉呈现。
- 文件对话框未绑定主窗口：导入、主题包和素材选择均绑定当前窗口，避免对话框出现在窗口后方。
- 回响出处按钮把完整选文拼入 GPUI 控件标识，复杂三段回响在原生渲染时触发栈溢出：改为稳定的引用 ID，并新增多原文回响原生回归测试。
- 用户点击打开书籍后，绑定窗口的 80ms 轮询任务从 GPUI 的 `spawn_in` 上下文退出，WebView 的 `ready` 消息无人读取，20 秒兜底恢复也停止运行，界面永久停在“正在铺开这一页”。轮询改为持有 `AnyWindowHandle` 的独立任务，在 WebView 创建后继续接收消息；新增延迟打开的原生回归路径，发布版实测通过。
- 部分 EPUB 在初始封面或正文资源长时间等待时，目录发送被阻塞：目录改为首屏前发送，书籍结构、目录、正文和位置各自设置超时，首屏失败时重建阅读面并跳转到备用目录项；原生端连续 20 秒未报告就绪时自动重建一次 WebView。
- 翻页后出现书签提示会使 WebView 高度变化并触发重排，旧 CFI 把读者带回上一页：翻页完成后主动确认最新位置，阅读页提示移到底部固定栏，不再改变 WebView 尺寸。
- 深色主题只覆盖 `body`，EPUB 内部显式黑色文字和亮色滚动条破坏夜景阅读：正文所有元素统一继承主题颜色与字体，滚动条使用当前主题的纸张、墨色与强调色。
- 没有历史位置时直接打开前置版权页，用户容易误以为书页仍在加载：未保存位置时优先定位目录中的正文第一章；已有 CFI 仍按原位置恢复。
- 长书进入三段原文回响时，GPUI 测试窗口接近 Windows 默认主线程栈上限：Windows 可执行文件显式保留 8 MB UI 栈，并用真实长书完成首次打开与重启恢复两次原生流程。
- 首版视觉首页主图在纵向弹性布局中被压缩：固定主视觉尺寸，并调整封面与首页留白，使首屏同时呈现场景、书架和主阅读按钮。
- 侧栏当前项强调底色被框架状态样式覆盖：将选中底色移至稳定的语义容器，保留图标、文字、悬停和辅助技术状态。
- 发布包会把本地运行产生的 30 MB WebView2 缓存一并打入 ZIP：把 WebView2 数据目录改到应用数据根下的 `webview`，并让打包脚本在路径校验后清空并重建发布暂存目录。
